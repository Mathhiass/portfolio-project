# Kali.Dev — Oliver Bartolata

A complete Next.js App Router portfolio with TypeScript, Tailwind CSS, original project media, light/dark themes, accessible navigation, and reduced-motion support.

Use Node 24 LTS or Node 22.13+.

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

```bash
npm run lint
npm run typecheck
npm run build
npm start
# In another terminal, while the server runs:
npm test
```

Deploy by importing the repository into Vercel as a Next.js project. Set `NEXT_PUBLIC_SITE_URL` to the final origin, then rebuild. No email service or secrets are needed.

Start reading at [Project Overview](docs/obsidian/00%20-%20Project%20Overview.md). See [Deployment Guide](docs/obsidian/07%20-%20Deployment%20Guide.md) for details and [Development Log](docs/obsidian/06%20-%20Development%20Log.md) for verification results.
