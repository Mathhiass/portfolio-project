## Direction

Taste Skill: **The name as a monument**, seed `1805059463`. On this page, Oliver Bartolata’s own name becomes the architecture between a frontend introduction and finished project interfaces. Following Oliver’s feedback, the full name sits together on one line in the hero. The footer uses the compact Kali.Dev wordmark, copyright and navigation; the oversized name has been removed.

Imbue display and Albert Sans body are self-hosted by next/font. Main palette adapts the dealt stone proportions to the explicit dark charcoal brief: charcoal #191b19, warm off-white #eeecea, sage #c3d5a5. Light mode reverses the foundation with a deliberate sage contact field. The dealt photographic hero is omitted because no honest full-bleed project photograph exists; the name-led direction takes priority. Stock landscape imagery would dilute the personal evidence.

The live interaction is Build something new / Care for what’s live: it changes a short explanation and leads to relevant evidence. It remains useful without hiding biography or projects.

## Tokens and behavior

All shared colors use CSS variables in app/globals.css. Page gutters scale from 20px to 56px. Headings have tight leading. Buttons have square corners; theme controls are round. No gradient or glass effects. The original portrait and project screenshots are the only photography/interface assets; no generated or third-party stock art.

At 700px the navigation becomes an accessible menu, split layouts stack, and project media use a closer crop. Reduced-motion disables entrance, scroll, and hover travel. Content stays visible if reveal script fails.
