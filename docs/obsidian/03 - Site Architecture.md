# Site architecture

Related: [[04 - Component Guide]], [[02 - Tech Stack]]

- `app/layout.tsx`: fonts, root HTML, global metadata, early theme restoration.
- `app/page.tsx`: all verified content and section layout. A project array keeps the two showcases consistent.
- `app/globals.css`: visual tokens, section geometry, both themes, responsive layouts, focus and motion rules.
- `components/interactions.tsx`: navigation, theme, work lens and reveal behavior. Only this module requires client JavaScript.
- `app/opengraph-image.tsx`: social preview image generated by Next.js.
- `app/sitemap.ts` and `app/robots.ts`: crawl information based on the final deployment origin.
- `public/images`: original portfolio media.
- `public/Oliver_Bartolata_Resume.pdf`: preserved original résumé.
- `docs/obsidian`: these learning notes.

The section order puts proof near the beginning: hero → projects → about → experience/education → skills → contact. Navigation links use stable anchor IDs.
